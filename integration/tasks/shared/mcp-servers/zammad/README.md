# MCP Zammad Server

Model Context Protocol (MCP) server for Zammad ticket system integration.

## Features

- Create and manage Zammad tickets
- List and search tickets
- Update ticket status and properties
- Manage ticket articles and comments

## Usage

This MCP server is used by the APEX evaluation harness to interact with Zammad ticket systems.

## Configuration

Set the following environment variables:
- `ZAMMAD_BASE_URL`: Base URL of your Zammad instance
- `ZAMMAD_API_TOKEN`: API token for authentication
